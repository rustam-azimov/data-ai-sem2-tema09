Задай вопрос документам

Один и тот же каталог: фильтруйте товары, исследуйте отзывы и выбирайте структуру под конкретный вопрос.

Учебный движок в браузере, не сервер MongoDB. Поддерживаются только операции, перечисленные ниже. Для домашней используются настоящие MongoDB-запросы в Mongo Playground.

Используйте JSON: ключи и строки в двойных кавычках. Здесь вводится объект фильтра либо массив pipeline, без db.collection.find(...).

Запрос для настоящего MongoDB
В Mongo Playground вставьте учебные документы в Database и этот запрос в Query. Для find используйте имя collection. В файле запросов указан тот же набор данных.
Границы учебного движка
Фильтр: равенство скаляру, $gte, $gt, $lt, $lte, $exists, $elemMatch; пути через точку. Pipeline: $match, $unwind (только массив с удалением пустых), $group с ключом поля и аккумуляторами $sum:1 и $avg: "$поле". Нет CRUD, индексов, BSON-типов, транзакций или сетевой базы. Неподдерживаемые операции отклоняются. Сравнение с null соответствует MongoDB: {brand:null} находит null и отсутствующее поле.
