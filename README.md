# Тема 09. Данные с гибкой структурой и NoSQL

Отдельный комплект курса «Данные как основа ИИ», бакалавриат, семестр 2.

## Что готово

- `index.html` — материалы темы.
- `04_ИНТЕРАКТИВЫ/Тренажер_09_JSON.html` — API и пагинация, структура JSON, раскрытие массива, экспорт двух связанных таблиц, загрузка JSON своего варианта, проверка вывода ИИ.
- `04_ИНТЕРАКТИВЫ/Тренажер_09_документы.html` — девять заданий, конструктор и JSON-редактор, фильтры и pipeline, выбор модели, прогресс и протокол.
- `03_ЛАБОРАТОРНЫЕ/ЛР_09.html` — домашняя по реальному MongoDB в Mongo Playground; три варианта, пять запросов, таблицы и проверка ИИ.
- `read/09.html`, `09_ПРЕЗЕНТАЦИИ/Тема_09.html` — заглушки теории и слайдов с планом.
- `05_ДАННЫЕ_СТУДЕНТАМ/` — снимок DummyJSON и изменённая учебная выборка; паспорт перечисляет все изменения.
- `scripts/download_api.py` — получение своего варианта из API либо явный выбор из снимка, без сторонних пакетов.

## Открыть локально

Из корня репозитория:

```sh
python3 -m http.server 8009
```

Откройте http://localhost:8009/ . Тренажёры работают на встроенных данных без внешних библиотек. Интернет нужен только для живого API и Mongo Playground.

## Границы

Браузерный движок — ограниченный учебный исполнитель, не MongoDB. Поддержка: скалярное равенство, числовые $gte/$gt/$lt/$lte, $exists, $elemMatch; стадии $match, $unwind (массив верхнего уровня, удаляет пустые), $group (ключ скалярного поля, $sum:1, $avg числового поля). Неподдерживаемые операции отклоняются; eval не используется.
В домашней применяются реальные MongoDB-запросы; браузерный движок для домашней проверки не используется.
JSON — формат обмена; API — способ доступа; MongoDB — документная СУБД с BSON. Другие семейства NoSQL и возможность хранения JSON в SQL рассмотрены в лонгриде.

## Проверка

```sh
python3 scripts/build_data.py
node scripts/check_data_engine.cjs
python3 scripts/check_download.py
node scripts/check_browser.cjs http://localhost:8009
```

Для браузерной проверки нужен установленный Playwright и Chrome. Путь к модулю можно передать через `PLAYWRIGHT_MODULE`.

## Публикация и LMS

GitHub Pages: ветка main, корень /. Все учебные HTML используют относительные ссылки. Для LMS размещайте весь комплект вместе, тренажёры подключайте iframe. Страницы сами не создают внешних соединений с базами и не содержат учётных данных.
Видео отмечены `data-video-slot`: два в практике, одно в домашней, два в лонгриде. Заменяйте блоки на запись соответствующей демонстрации.
